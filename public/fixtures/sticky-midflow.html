Sticky element authored mid-document

This document places a position: sticky; top: 0 block roughly in the middle of a multi-page document. Naively converting sticky to absolute while keeping top: 0 would pin it to the containing block's origin — page 0 — no matter where it was authored.

Neutralizing the inset keeps the converted element at its static position, so it stays on the page its surrounding content lands on. The test asserts the sticky block is NOT on page 0.
