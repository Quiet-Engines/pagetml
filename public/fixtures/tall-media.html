Oversized elements

An inline SVG declared far larger than a page. Normalization must scale it to fit within a single page rather than letting it clip or overflow the counted pages.

A long preformatted code block. Because a single very long line cannot be broken by default, the engine's base style allows it to wrap so it fragments across pages instead of clipping.

function paginate(flow, viewportWidth, viewportHeight, gap) {
  // This intentionally long comment line simulates the kind of unbreakable preformatted content that would otherwise overflow a fixed-width column and be clipped at the page boundary without wrapping enabled by the engine base stylesheet.
  const stride = viewportWidth + gap;
  const pageCount = Math.max(1, Math.round((flow.scrollWidth + gap) / stride));
  return { stride, pageCount };
}
