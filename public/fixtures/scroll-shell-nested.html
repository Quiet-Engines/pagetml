Nested single-page-app shell

The scrolling container that holds all content is nested one level below body (inside .frame). The old detector only inspected body and its direct children, so it never saw this element and the document collapsed to a single page. The measurement-based detector inspects the whole subtree and identifies any viewport-sized box that clips its overflow.
