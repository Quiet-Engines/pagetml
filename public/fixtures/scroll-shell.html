Single-page-app shell

All of this content lives inside one element with height: 100vh and overflow: auto. Left alone, it produces exactly one page because the content never flows past the viewport-height box — everything beyond the first screen is hidden behind an internal scrollbar.

The engine detects this pattern and unwraps it: height becomes auto and overflow becomes visible, so the content flows into columns and paginates normally. This paragraph and the following ones exist to prove that the unwrapped content spans several real pages.
