Quarterly Field Notes

This document imitates a word-processor export, with each run of text wrapped in its own styled span and every paragraph tagged with generated class names. Such exports are a primary real-world input for the pagination engine.

The engine must flow this nested markup into columns without being confused by the wrapper spans, and without any run of text being clipped at a page boundary. See the reference link which opens externally in the real app.

Findings

  • Nested inline spans do not, by themselves, prevent fragmentation; the browser breaks between lines regardless of wrapper depth.
  • Per-run font sizes in points scale with the document, so page counts shift with window size exactly as auto-fit intends.
  • Generated class names are inert to the engine; only computed layout matters.

The remaining paragraphs pad the document so it spans several pages at typical window sizes, giving the resize round-trip and anchor-containment checks genuine content to operate against.
